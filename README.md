# CleanArenaFrames

Strips the clutter from Blizzard's arena frames so enemy health and casts read at a glance.

## Features

- Arena frame accessories repositioned for visibility
- Default casting bars hidden or simplified
- Decorative frame elements removed
- No configuration and no saved settings

## Installation

1. Copy the `CleanArenaFrames/` folder into `World of Warcraft/_retail_/Interface/AddOns/`.
2. Restart the game or `/reload`.
3. Enable **Clean Arena Frames** in the AddOns list.

## Requirements

World of Warcraft Retail (Interface `120005`).
